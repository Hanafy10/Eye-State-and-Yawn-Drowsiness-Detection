# Eye State and Yawn Drowsiness Detection
Real time drowsiness detection using computer vision and deep learning.

## Features

- Eye state detection (open/closed)
- Yawn detection
- Real-time webcam monitoring
- Alarm for drowsiness
- OpenCV face and eye detection
- TensorFlow and PyTorch models

## Technologies Used

- Python
- OpenCV
- TensorFlow
- PyTorch
- NumPy

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPO.git
cd YOUR_REPO
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## Run the Project

```bash
python drowsiness_final.py
```
